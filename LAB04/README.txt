# Digital Image Processing Lab 04

## Project contents
- `2024-SET-YOUR_ROLL_NO-LAB04.ipynb` — completed Jupyter Notebook
- `image.jpg` — input image supplied for this lab
- `transformed_images/` — saved transformed images and interpolation comparisons

## Before submission
1. Open the notebook and replace the student name and roll number placeholders.
2. Rename the notebook using your actual roll number, following the instructor's naming format:
   `2024-SET-YOUR_ROLL_NO-LAB04.ipynb`
3. Keep `image.jpg` in the same folder as the notebook.
4. Run all cells from a restarted kernel.
5. Upload the notebook, `image.jpg`, and the complete `transformed_images` folder to your GitHub repository.
6. Submit the accessible repository link.

## Required Python libraries
- opencv-python
- numpy
- matplotlib
