# DIP Lab Task 05 — Spatial Filtering and Convolution

## Files
- `2024-SET-YOUR_ROLL_NO-LAB05.ipynb`: completed Jupyter Notebook with code, calculations, figures, checks, observations and viva answers.
- `README.md`: project instructions.
- `requirements.txt`: Python packages needed to run the notebook.

## Before submission
1. Open the notebook.
2. Replace `REPLACE_WITH_YOUR_ROLL_NUMBER` with your complete roll number.
3. Rename the notebook according to your roll number, for example:
   `2024-SET-<YOUR_ROLL_NUMBER>-LAB05.ipynb`
4. Restart the kernel and run all cells from top to bottom.
5. Check that all output figures and printed checks are visible.
6. Upload the notebook and README to an accessible repository.

## Run
Install the requirements, then open the notebook in Jupyter Notebook or JupyterLab.

```bash
pip install -r requirements.txt
jupyter notebook
```

The notebook uses the Camera, Coins and Chelsea images supplied by `scikit-image`, and also includes the user's uploaded robot-painting picture as the grayscale variable `image`.


## Uploaded image
Place the uploaded picture in the same working folder as the notebook and update the image path in the image-loading cell if needed. The submitted version currently reads `/mnt/data/hehe(3).jpg` in this environment.
